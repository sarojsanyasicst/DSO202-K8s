# Shared acceptance testing

This directory will contain disposable PostgreSQL/RabbitMQ configuration, shared acceptance helpers, and traffic-runner checks. Backend tests live in `services/backend/tests/`; frontend browser tests live in `services/frontend/tests/`; Prometheus rule tests live in `monitoring/tests/`.

No application tests have been implemented or run. Current structure/documentation validation is recorded in [VERIFICATION.md](../docs/project/VERIFICATION.md).
