# Storefront

Planned React/TypeScript application. `src/features/` groups catalog, cart, orders, and instructor admin screens; `public/products/` holds bundled product images; `tests/` holds browser acceptance tests.

Consume the backend's OpenAPI contract and same-origin session cookies. Make queued/processing/completed/failed behavior and the release version visible without exposing infrastructure settings to shoppers.

This is folder structure only. The application, package manifest, build configuration, and browser tests belong to P05 in the [implementation plan](../../docs/superpowers/plans/2026-10-16-cloudcart-implementation.md).
